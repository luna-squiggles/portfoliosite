# Simple Portfolio Site

This repository hosts my dynamically updated portfolio site. The scope of the project has been met, so unless specific requests for features are made, expect the current stabe release to recieve limited updates.

## 💛 Features
- **Dynamic Layout**: Upload any number of images and the Layout will compensate.
- **Image Resizing**: Upload images in any common format and they will be resized and converted to webp for a responsive site.
- **Intuitive Metadata**: Metadata will be applied based on the title of the image, but can be edited manually.
- **Organised file structure**: Easy, readable, and perfect for adding features to.

## 🔧 Try it for yourself!

To run this project clone the repo, upload your own photos in a folder titled 'assets' and commit. Message me for any implementation assistance.
